# Contribution à FASTEK-CENTRAL-ADMIN

## Branches
- `main` : production (protégée)
- `develop` : intégration
- `staging` : validation
- `feature/xxx` : nouvelles fonctionnalités
- `fix/xxx` : corrections

## Commits
Utiliser Conventional Commits :
- `feat:` nouvelle fonctionnalité
- `fix:` correction
- `docs:` documentation
- `chore:` maintenance
- `test:` tests
- `refactor:` refactoring

## Secrets
Aucun secret ne doit être commité.
Utiliser GitHub Secrets et les variables d'environnement Cloudflare Pages.

## Interface
- Couleurs officielles : `#2C2C2C`, `#0047AB`, `#FF6B00`, `#FFFFFF`
- Français en V1
- Interface adaptative (ordinateur, tablette, téléphone)

## Pull Requests
- Une PR = une intention claire
- Description obligatoire
- Tests et lint doivent passer
